# Incident Response

Pause affected adapters or runners after source blocks, policy concerns, quota
warnings, credential exposure, or incorrect personal-data exposure. The current
local phases have no active production adapters or runners.

The active phase is Phase 7 and remains local-only. If exercising the partial
Phase 10A local runner readiness code, also pause local smoke or spool replay if
the runner lock appears stale, a spool checksum fails, a replayed batch is
rejected by validation, or a forbidden browser profile/cookie path is detected.
Do not delete canonical or historical data during incident recovery.
